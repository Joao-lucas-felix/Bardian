# Código legado do Bardian

Esta pasta preserva protótipos e superfícies anteriores do TCC para consulta
acadêmica, comparação e eventual recuperação.

O conteúdo aqui não participa do fluxo atual: não é rota pública, não é carregado
pelo layout ativo, não é registrado pelo Stimulus e não deve ser tratado como parte
da implementação vigente.

O fluxo ativo está limitado a autenticação, CRUD de composições, modelagem musical
básica e composição persistida de harmonias com reprodução openDAW.

Os testes arquivados nesta pasta são referências históricas. Eles não fazem parte
da suíte de regressão do produto atual, porque verificam rotas e componentes que
foram deliberadamente retirados do ar.
